# Chapter Leader OS

Minimalny system zarządzania pracą Chapter Leadera IT oparty o **Obsidian + Todoist**.

## Zawartość

- `templates/` — gotowe szablony Obsidiana: Daily, Meeting, 1:1, Person, Decision, Weekly Review.
- `how to/` — instrukcja konfiguracji i 14-dniowego wdrożenia systemu.

## Zacznij tutaj

Otwórz: `how to/01-START-HERE.md`.

## Filozofia

**Obsidian = pamięć i kontekst.**  
**Todoist = zobowiązania i kontrola wykonania.**

Nie duplikuj pełnych list zadań w Obsidianie.
