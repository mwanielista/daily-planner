# Chapter Leader OS — start tutaj

System ma tylko dwie warstwy:

- **Obsidian = pamięć i kontekst** — co się wydarzyło, decyzje, spotkania, ludzie, ryzyka.
- **Todoist = działanie** — co trzeba zrobić, czego trzeba dopilnować i kiedy do tego wrócić.

## Zasada kwalifikacji informacji

| Informacja | Gdzie trafia |
|---|---|
| Muszę coś zrobić | Todoist |
| Ktoś ma coś zrobić, a ja mam dopilnować | Todoist + `%waiting` |
| Muszę wrócić do sprawy | Todoist + `%followup` |
| Temat na rozmowę 1:1 | Todoist + `%1on1` |
| Coś wydarzyło się na spotkaniu | Obsidian Daily / Meeting |
| Zapadła ważna decyzja | Obsidian |
| Ważna wiedza o osobie / zespole | Obsidian |

## Minimalny rytm

1. Rano: Daily Note + Todoist ACTION; wybierz TOP 3.
2. Spotkania: notuj D/A/F/R/B/?.
3. W ciągu dnia: każde nowe zobowiązanie przechwytuj w Todoist Inbox.
4. Koniec dnia: przetwórz notatki, wyczyść Inbox, przygotuj jutro.
5. Raz w tygodniu: Weekly Review.

Przejdź dalej do `02-OBSIDIAN-SETUP.md`.
